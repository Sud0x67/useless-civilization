# 无用文明 · Useless Civilization

一座漂浮在夜空中的小镇，六位性格不同的居民，和一个偶尔添乱的人类观察员。居民的**行动、对白与公开行动说明默认全部来自真实模型**，没有脚本对白或离线模拟模式。

项目位置：`~/code/useless-civilization`。目前是本地应用，尚未发布到公网或绑定 `useless-llm.com`。

## 启动

需要 Node.js **24.15.0 或更新的 24.x**、npm 和现代浏览器。

```sh
cd ~/code/useless-civilization
nvm use 24  # 或使用你安装的 Node.js 24
npm ci
cp .env.example .env  # 首次配置；已有 .env 时请勿覆盖
# 编辑 .env 中的 LLM_API_KEY
chmod 600 .env
npm run dev
```

访问 http://127.0.0.1:4180 。进入页面且连接配置完整时，会立即进行第一轮模型调用，然后默认每 20 秒尝试一轮。可以随时暂停、逐轮运行或调整速度。访问 `http://127.0.0.1:4180/?paused=1` 可先以暂停状态进入。服务器默认只监听本机。

本机已按用户提供的 Token Plan 配置创建 `.env`，不需要重新填写。密钥不会写入代码、Git、浏览器存储或回放文件。更改服务器代码或 `.env` 后需要重启服务。

```dotenv
LLM_BASE_URL=https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen3.8-flash
LLM_WIRE_API=responses
LLM_API_KEY=填写你自己的密钥
PORT=4180
```

使用 `/responses`、Bearer 认证、`reasoning.effort=none`、`store=false`。可用 `LLM_WIRE_API=chat` 切换到支持 `enable_thinking=false` 的 Chat Completions 兼容服务。不同供应商的扩展参数可能需要调整 `server/model.mjs`。

## 怎么玩

- 拖动旋转浮岛，滚轮缩放。点击地图姓名或左侧居民卡片，查看目标、需求、记忆、关系与最近对白。
- 六位居民：镇长米拉、商人奥托、农夫小林、工程师阿达、艺术家回声、哲学家索伦。角色性格和人生目标会发送给模型。
- 每轮由一个模型请求为六位居民共同做决定。完整、有效的决策才会推进 15 分钟世界时间，角色会走向模型选择的地点。
- 「投放事件」支持全民镇长、夸奖变成货币、禁止开会、交换记忆、免费面包、星星雨。提交后自动生成居民反应，无需先暂停或手动运行一轮。正在进行的自动决策会让位，已有的人类操作按顺序完成。
- 「作为人类加入」让观察员出现在广场。选择居民后默认打开「对话」，可随时输入并发送；每位居民的草稿独立保留。聊天记录单独保存最近 120 条消息，不会被自动动态覆盖；单人模型请求附带该居民最近 8 条对话。
- 时间线可以查看最近 120 个世界快照。回放模式只读，不调用模型。导入后默认停在回放，返回当前世界并点击播放即可继续。
- 导出/导入 JSON 回放以保存和恢复进度。最大 5 MB；导出超过限制时保留较新的快照。刷新页面会清空世界、对话和内存中的回放。
- 默认静音，设置中可开启浏览器内置语音朗读对话回复。设备不支持 WebGL 时降为可交互的轻量地图。

## 模型与世界的边界

模型决定 `action`、`location`、`speech`、公开的 `reason`，以及互动对象与意图；所有输出经过 Zod 校验，不执行模型生成的代码或工具调用。`reason` 是给观察员看的短行动说明，不请求或展示隐藏思考过程。

程序只执行世界的物理规则：需求随时间变化、工作/休息影响资源、农场生产食物、市场进食、互动改变关系、影响力与定期值班镇长、事件效果与到期。禁止开会时，镇公所的社交提案会被拒绝并显示系统说明，**不会生成替代对白**。夸奖货币期间，市场进食需要向奥托发出夸奖互动。

初始世界旁白、界面文字和用户投放事件的说明来自程序；居民实际的行动和对白来自模型。模型失败、超时、输出格式错误时，保留上一次有效世界并暂停，点击重试恢复。

## 调用与数据

- 默认 `qwen3.8-flash`；每轮六人共用一次请求，输出上限 1,800 tokens；单人对话上限 300 tokens。没有自动切换到其他模型。
- 速度为每 20 / 12 / 8 秒尝试一轮；已有请求执行时跳过本轮。人类提交会中止正在进行的自动决策并优先执行；人类请求之间不互相打断，最多保留 12 项操作。排队期间停止自动决策，全部处理完后按原来的运行/暂停状态继续，并重新等待一个完整运行间隔。打开事件面板或编辑草稿不暂停小镇。页面隐藏或进入回放时中止请求，未完成的人类操作保留在队列，返回后继续；可见且连续 10 分钟无操作时自动暂停。
- 模型返回错误后暂停，不无限重试。失败的人类操作和后续队列会保留，可重试或跳过本次回应；重试不重复投放事件或记录问题。等待中的操作可以取消。服务器限制每分钟最多 12 次请求、最多 2 个并发请求、每次默认 30 秒超时。
- 角色状态、最近记忆、最近动态以及你输入的对话会经本地服务器发送给所配置的模型供应商。请勿在对话中输入不希望发给该供应商的信息。
- 页面不使用 localStorage、sessionStorage、Cookie 或外部 CDN；依赖随站点构建。密钥只在服务器环境中，前端只获知模型名称和配置状态。
- 页脚统计本次页面会话中**成功返回的请求**及供应商报告的 token 用量；不是账单，失败或取消的请求仍可能被供应商计费。
- 回放文件包含世界与已执行的对话，分享前可自行检查；不包含服务器配置、API 密钥、尚未执行的排队操作和草稿。刷新、导入其他世界或重置会清空当前队列和草稿；旧版回放仍可导入。

## 开发与验证

React 19 + TypeScript + Vite 8 + Three.js，Node.js 内置 HTTP 服务器，无数据库。场景由几何体和本地 SVG 构建，无外部素材下载。

```sh
npm test                         # 世界状态、回放、代理协议与错误处理
npm run build                    # 类型检查与生产构建
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e                  # Chromium / Firefox / 移动 WebKit
npm run format:check
npm run format
npm start                        # 生产服务器，先 build
```

自动化测试使用本地假上游/浏览器请求拦截，**不消耗真实模型额度**。真实 Token Plan 已单独验证 Responses 连通性、六人批量输出、事件反应与居民对话。手动运行 `node tests/manual-model-smoke.mjs` 会针对运行中的本地服务器发出 3 次真实模型请求，请按需执行。

主要代码：

- `src/App.tsx`：交互、暂停、回放和导入导出。
- `src/world/request-scheduler.ts`：人类优先、自动请求中断、队列、重试和恢复。
- `src/components/Conversation.tsx`：独立的居民对话记录与输入。
- `src/components/Town.tsx`：Three.js 场景、居民移动、视角与轻量地图。
- `src/world/engine.ts`：纯函数世界状态与物理后果。
- `src/shared/schema.ts`：模型、世界与回放数据校验。
- `server/model.mjs`：供应商协议、提示词、超时与输出校验。
- `server/app.mjs`：同源 API、限流、生产静态文件服务。

GitHub Actions 只做构建与测试，不部署，不需要模型密钥。

## 后续部署

这个项目有服务器端模型代理，**不能只部署到 GitHub Pages**。后续可以部署到支持 Node.js 24 的主机，再在服务器环境中设置密钥并绑定域名。

如需公网开放，需要先加访问认证和按访客的额度控制；当前内存限流适合本地体验，不能替代公网用户鉴权。默认 `HOST=127.0.0.1`。反向代理 HTTPS 时可配置 `PUBLIC_ORIGIN=https://你的域名` 以接受正确的同源请求。重启会清空限流计数；世界状态仍由各浏览器内存维护。
